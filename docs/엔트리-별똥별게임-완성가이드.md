# 엔트리 「별똥별 피하기」 완성 가이드

수행평가용 엔트리 작품을 **완성 상태**로 만들기 위한 블록 설계서입니다.
플레이 가능한 레퍼런스: `web/index.html`

---

## 0. 무대 규격 (가장 중요)

엔트리 무대는 **480 × 270**, 좌표 범위는 다음과 같습니다.

| 축 | 범위 |
|---|---|
| x | −240 ~ 240 |
| y | −135 ~ 135 |

현재 작품의 `별똥별위치리셋` 함수에 있는 `y: 240`은 **무대 밖**입니다. → `y: 130`으로 수정.

---

## 1. 지금 고장난 원인 2가지

### 버그 1 — 별똥별이 한 번만 떨어진다
`계속 반복하기` 안에 **바닥 도달 판정이 없습니다.**
별똥별은 화면 아래로 사라진 뒤에도 계속 −y 방향으로 내려가고 있을 뿐,
위로 다시 올라오는 블록이 없어서 "한 번 떨어지고 끝"으로 보입니다.

떠 있는 `떨어진횟수 값 > 74` 블록이 어디에도 연결되어 있지 않은 것도 같은 맥락입니다.

### 버그 2 — 캐릭터가 벽을 통과한다
엔트리는 오브젝트가 무대 밖으로 나가는 것을 **막아주지 않습니다.**
"벽에 닿으면 죽기"를 원하면 반복문 안에서 직접 판정해야 합니다.

> ⚠️ 함정: `벽에 닿았는가?`를 그대로 쓰면 바닥에 서 있는 우주인이
> **아래쪽 벽에 이미 닿아 있어서** 시작하자마자 죽습니다.
> → 좌·우만 판정하거나 `x좌푯값`으로 비교하세요.

---

## 2. 사전 준비

| 종류 | 이름 | 비고 |
|---|---|---|
| 변수 | `점수` | 보이기 |
| 변수 | `속도` | 숨기기 (난이도 상승용) |
| 변수 | `생성간격` | 숨기기 (난이도 상승용) |
| 리스트 | `기록` | 게임 종료 시 점수 누적 |
| 신호 | `게임오버` | **[속성] 탭에서 새로 만들기** — 사망 처리를 한 곳으로 모읍니다 |

기존 `떨어진횟수` 변수는 쓰지 않아도 됩니다. 남기려면 바닥 판정에서 함께 1 더하세요.

## 3. 오브젝트별 블록 조립표

### 우주인(1)

**스크립트 A — 조종**
```
[시작하기 버튼을 클릭했을 때]
x: (0) y: (-100) 위치로 이동하기
계속 반복하기
    만일 〈왼쪽 화살표 키가 눌러져 있는가?〉 이라면
        x 좌표를 (-7) 만큼 바꾸기
    만일 〈오른쪽 화살표 키가 눌러져 있는가?〉 이라면
        x 좌표를 (7) 만큼 바꾸기
```
> "키를 눌렀을 때" **이벤트**가 아니라, 반복문 안의 "눌러져 있는가?" **판단**이어야
> 키를 누르고 있는 동안 부드럽게 움직입니다.

**스크립트 B — 벽 충돌 (버그 2 해결)**
```
[시작하기 버튼을 클릭했을 때]
계속 반복하기
    만일 〈 〈자신의 x좌푯값 < -215〉 또는 〈자신의 x좌푯값 > 215〉 〉 이라면
        ("벽에 부딪혔다!") 을(를) 말하기
        [게임오버] 신호 보내기
        자신의 코드 멈추기
```
조립법: [계산] `자신의 x좌푯값` 블록 2개 → [판단] `<` 와 `>` 블록에 각각 끼우고
→ [판단] `또는` 블록 양쪽에 끼웁니다.

대안: `〈왼쪽 벽에 닿았는가?〉 또는 〈오른쪽 벽에 닿았는가?〉`

**스크립트 C — 사망 처리**
```
[게임오버 신호를 받았을 때]
(기록) 에 (점수 값) 항목 추가하기
("게임 오버! 점수 " 와(과) (점수 값) 을 합치기) 을(를) 말하기
모든 코드 멈추기
```
> `모든 코드 멈추기`는 **반드시 맨 마지막**. 위에 두면 기록·말하기가 실행되지 않습니다.

### 별똥별(2)

**스크립트 A — 생성기 (본체는 숨어서 복제본만 찍어냄)**
```
[시작하기 버튼을 클릭했을 때]
(점수) 를 (0) 으로 정하기
(속도) 를 (4) 으로 정하기
(생성간격) 을 (0.45) 으로 정하기
모양 숨기기
계속 반복하기
    자신의 복제본 만들기
    (생성간격 값) 초 기다리기
```

**스크립트 B — 복제본 한 개의 일생 (버그 1 해결)**
```
[복제본이 처음 생성되었을때]
x: (-220 부터 220 사이의 무작위 수) y: (130) 위치로 이동하기
모양 보이기
계속 반복하기
    y 좌표를 ((속도 값) × (-1)) 만큼 바꾸기
    만일 〈우주인(1) 에 닿았는가?〉 이라면
        [게임오버] 신호 보내기
        자신의 코드 멈추기
    만일 〈자신의 y좌푯값 < -130〉 이라면
        (점수) 에 (1) 만큼 더하기
        이 복제본 삭제하기
```
> 🔴 `이 복제본 삭제하기`가 없으면 복제본이 수백 개 쌓여 작품이 느려지다 멈춥니다.
> 가장 흔한 사고입니다.
>
> 본체를 숨겼으므로 복제본에서 `모양 보이기`는 **필수**입니다.
>
> 변수를 안 쓰려면 `y 좌표를 (-4) 만큼 바꾸기`로 단순화해도 됩니다.

**스크립트 C — 난이도 상승 (선택)**
```
[시작하기 버튼을 클릭했을 때]
계속 반복하기
    만일 〈점수 값 > 9〉 이라면
        (속도) 를 ( 4 + ((점수 값 / 10) × 0.5) ) 으로 정하기
        (생성간격) 을 ( 0.45 - ((점수 값 / 10) × 0.03) ) 으로 정하기
```

### 우주(2) · 배경
건드릴 것 없습니다. 안내 문구만 선택적으로:
```
[시작하기 버튼을 클릭했을 때]
("← → 로 별똥별을 피하세요!") 을(를) (2) 초 동안 말하기
```

## 4. 지금 작품만 빠르게 살리는 3분 패치

복제본까지 안 가고 별똥별 1개로 끝내려면:

1. `별똥별위치리셋` 함수 → `y: 240` 을 `y: 130` 으로, 무작위 수는 `-220 ~ 220`
2. 별똥별 반복문 **맨 아래**에 추가
   ```
   만일 〈자신의 y좌푯값 < -130〉 이라면
       (점수) 에 (1) 만큼 더하기
       별똥별위치리셋
   ```
   → 이 한 덩어리가 "계속 떨어짐 + 점수 상승"을 동시에 해결합니다.
3. 우주인에 **스크립트 B(벽 충돌)** 추가
4. 떠 있는 `떨어진횟수 값 > 74` 블록 삭제
5. 빈 `만일 〈참〉 이라면` 블록 삭제
6. 별똥별 오브젝트를 2~3개 복사하면 "여러 개가 떨어지는" 느낌까지 완성

## 5. 제출 전 체크리스트

- [ ] 바닥에 닿은 복제본에 `이 복제본 삭제하기`가 있는가
- [ ] 복제본 스크립트에 `모양 보이기`가 있는가
- [ ] 좌표가 무대 범위(x −240~240, y −135~135) 안인가
- [ ] `벽에 닿았는가?`를 좌·우만 판정하는가 (아래쪽 벽 즉사 방지)
- [ ] `모든 코드 멈추기`가 기록·말하기보다 **뒤**에 있는가
- [ ] 충돌 판정이 한 곳(=`게임오버` 신호)으로 모였는가 (기록 중복 방지)
- [ ] 시작할 때 `점수`가 0으로 초기화되는가
- [ ] `계속 반복하기`는 초당 약 60회 — 속도 숫자를 실제로 플레이해 보고 정했는가

## 6. 블록에 들어가는 숫자 요약

| 항목 | 값 | 블록 |
|---|---|---|
| 캐릭터 시작 위치 | x 0 / y −100 | x: 0 y: −100 위치로 이동하기 |
| 캐릭터 이동량 | ±7 | x 좌표를 ±7 만큼 바꾸기 |
| 벽 사망 기준 | \|x\| > 215 | 자신의 x좌푯값 비교 |
| 별똥별 생성 y | 130 | y: 130 위치로 이동하기 |
| 별똥별 생성 x | −220 ~ 220 | 무작위 수 |
| 낙하 속도 | −4 / 프레임 | y 좌표를 −4 만큼 바꾸기 |
| 생성 간격 | 0.45초 | 0.45 초 기다리기 |
| 바닥 통과 기준 | y < −130 | 자신의 y좌푯값 비교 → 점수 +1 |
| 난이도 상승 | 10점마다 | 속도 +0.5 / 간격 −0.03 |
