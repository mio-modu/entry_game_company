# entry_game_company

엔트리(playentry.org) 기반 게임 기획·제작 자료.

## 별똥별 피하기 (수행평가)

| 파일 | 내용 |
|---|---|
| `docs/엔트리-별똥별게임-완성가이드.md` | 블록 조립표 · 버그 진단 · 체크리스트 |
| `web/index.html` | 플레이 가능한 완성본 레퍼런스 (엔트리와 동일 좌표계·프레임) |

`web/index.html`은 엔트리 무대 규격(480×270, x −240~240 / y −135~135)과
60fps 루프를 그대로 재현합니다. 페이지 안의 슬라이더로 맞춘 숫자를
그대로 엔트리 블록에 옮겨 적으면 같은 난이도가 나옵니다.

### 로컬 실행
```
python3 -m http.server 8000 -d web
# http://localhost:8000
```
