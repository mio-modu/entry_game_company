# 사전 데이터 라이선스

이 게임이 쓰는 낱말·뜻풀이 자료는 **세 가지 출처**에서 왔고, **라이선스가 서로 다릅니다.**
한 줄로 묶어 적으면 안 됩니다.

| 파일 | 내용 | 원 출처 | 라이선스 |
|---|---|---|---|
| `words.js` → `WORDS_SEED` | 출제용 3,392 낱말 | 국립국어원 **한국어 학습용 어휘 목록**(2019 수정본) 명사 | **공공누리 제1유형** (출처 표시) |
| `words.js` → `WORDS_ACCEPT` | 판정용 191,684 낱말 | 국립국어원 **표준국어대사전** 명사 | **CC BY-SA 2.0 KR** |
| `defs.js` → `DEFS` | 뜻풀이 25,869개 | 국립국어원 **한국어기초사전** | **CC BY-SA 2.0 KR** |

두 사전 자료는 GitHub 공개 저장소를 거쳐 받았습니다
(`han-dle/pd-korean-noun-list-for-wordles`, `tinyrack-net/dictionary`).
중계 저장소의 라이선스 표기와 무관하게 **원 저작물의 조건이 따라옵니다.**

## 지켜야 할 것

**출처 표시** — 세 자료 모두. 앱 안에 출처 화면을 두고 아래를 적습니다.

```
낱말·뜻풀이 자료
  한국어 학습용 어휘 목록 (2019 수정본) ⓒ 국립국어원 — 공공누리 제1유형
  표준국어대사전 ⓒ 국립국어원 — CC BY-SA 2.0 KR
  한국어기초사전 ⓒ 국립국어원 — CC BY-SA 2.0 KR
  https://korean.go.kr  https://stdict.korean.go.kr  https://krdict.korean.go.kr
```

**동일조건변경허락(ShareAlike)** — `WORDS_ACCEPT`와 `DEFS`에만 걸립니다.
이 두 자료를 추려·가공한 결과물은 **같은 CC BY-SA 2.0 KR로 공개**해야 합니다.
`WORDS_SEED`(공공누리 1유형)에는 이 의무가 없습니다.

**게임 코드에는 걸리지 않습니다.** 다만 사전이 코드 안에 인라인으로 박히거나
로직과 한 파일에서 섞이면 경계가 흐려집니다. 사전은 항상 별도 파일로 둡니다.

## 알아 두어야 할 것

ShareAlike가 걸린 자료는 누구나 받아 쓸 수 있게 됩니다. 경쟁자가 이 두 파일을
그대로 가져가는 것을 막을 법적 수단이 없습니다. **의식적으로 받아들이고,
자산을 데이터가 아니라 게임 설계에 두는 것**을 전제로 합니다.

두 층 사전 구조, 역산 기세, 산별 규칙은 파일을 받아도 따라오지 않습니다.

## 출시 전 확인

위 라이선스 구분은 2026년 11월 기준이며 2차 출처를 통해 확인한 것입니다.
**출시 전에 국립국어원 각 사이트의 저작권 안내에서 직접 재확인하십시오.**
특히 학습용 어휘 목록의 공공누리 유형(제1유형인지, 변경금지 조건이 붙는지)은
반드시 원문으로 확인해야 합니다.
