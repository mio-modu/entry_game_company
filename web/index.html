버그 1 · 별똥별이 한 번만

바닥에 닿았을 때 다시 위로 올려주는 블록이 없습니다. 지금 계속 반복하기 안에는 “우주인에 닿았는가”만 있어서, 별똥별은 화면 아래로 내려간 뒤 영원히 −y 좌표로만 내려갑니다. 화면 밖에서 계속 떨어지고 있는 거라 멈춘 것처럼 보일 뿐입니다.

또 하나: 별똥별위치리셋 함수의 y: 240은 엔트리 무대 밖입니다. 무대 세로 범위는 −135 ~ 135라서 y: 130이 맞습니다. 240이면 떨어지기 시작할 때까지 공백이 생깁니다.

버그 2 · 벽을 통과

벽 충돌을 검사하는 블록 자체가 없습니다. 엔트리는 오브젝트가 무대 밖으로 나가도 막아주지 않습니다. “벽에 닿으면 죽기”를 원하면 반복문 안에서 직접 판정해야 합니다.

함정: 벽에 닿았는가?를 그냥 쓰면 바닥에 서 있는 우주인이 아래쪽 벽에 이미 닿아 있어서 시작하자마자 죽습니다. 좌·우만 골라서 판정하거나, 아래 조립표처럼 x좌푯값으로 비교하세요.

가장 빠른 길

3분 패치 — 지금 작품을 그대로 살리기

복제본까지 안 가고, 별똥별 1개로 “계속 떨어지고 점수 오르고 벽에서 죽는” 상태까지는 블록 6개면 됩니다.

  1. 별똥별위치리셋 함수에서 y: 240 → y: 130
    무작위 수는 −220 부터 220으로. 캐릭터 크기만큼 여유를 둡니다.
  2. 별똥별 반복문 맨 아래에 바닥 판정 추가
    만일 〈자신의 y좌푯값 < −130〉 이라면 → 점수에 1 만큼 더하기 + 별똥별위치리셋. 이 한 덩어리가 “계속 떨어짐 + 점수 상승”을 동시에 해결합니다.
  3. 우주인에 벽 판정 반복문 추가
    만일 〈자신의 x좌푯값 < −215〉 또는 〈자신의 x좌푯값 > 215〉 이라면 → 게임오버 신호 보내기
  4. 떠 있는 떨어진횟수 값 > 74 블록은 삭제하거나 클리어 조건으로
    쓰려면 만일 〈점수 값 > 20〉 이라면 → "클리어!" 말하기 + 모든 코드 멈추기 형태가 깔끔합니다.
  5. 빈 만일 〈참〉 이라면 블록 제거
    조건이 항상 참이라 나중에 예상 못 한 분기를 만듭니다.
  6. 별똥별을 여러 개로 늘리려면 아래 조립표의 복제본 버전으로
    오브젝트를 3~4개 복사해도 되지만, 복제본 쪽이 블록이 더 적고 난이도 조절도 쉽습니다.

제출 전 체크리스트

  • 복제본 삭제 누락 — 바닥에 닿은 복제본은 반드시 이 복제본 삭제하기. 안 하면 수백 개가 쌓여 작품이 멈춥니다.
  • 모양 보이기 누락 — 본체를 숨겼으면 복제본 스크립트 맨 위에서 다시 보여야 합니다.
  • 무대 좌표 범위 — 엔트리 무대는 x −240~240, y −135~135. y: 240 같은 값은 화면 밖입니다.
  • ‘벽에 닿았는가?’ 즉사 — 바닥에 선 캐릭터는 아래쪽 벽에 이미 닿아 있습니다. 좌·우만 판정하세요.
  • ‘모든 코드 멈추기’ 위치 — 점수 기록·말하기보다 뒤에 와야 합니다.
  • 중복 사망 처리 — 충돌 판정을 별똥별과 우주인 양쪽에서 하면 기록이 두 번 쌓입니다. 게임오버 신호 하나로 모으세요.
  • 변수 초기화 — 점수는 시작할 때 0으로. 리스트 기록은 남겨두면 누적 기록이 됩니다.
  • 속도 체감 — 계속 반복하기는 초당 약 60번 돕니다. y −5면 1초가 채 안 돼 바닥에 닿습니다. 위 게임에서 먼저 맞춰보세요.
