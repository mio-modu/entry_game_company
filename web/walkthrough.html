엔트리 화면 오른쪽 위의 ≡ 모양 아이콘을 눌러보세요. 거기에 “내 컴퓨터에 저장하기”가 있으면, 그걸 눌러 받은 .ent 파일을 저에게 주시면 됩니다. 제가 안을 다 고쳐서 파일로 돌려드리고, 아버님은 “불러오기”만 누르시면 끝납니다.

그 메뉴가 없으면(수업 과제라 막혀 있을 수 있습니다) 아래 순서대로 하시면 됩니다. 다 해도 20분쯤입니다.

보이면 아래 쉬운 방법대로, 안 보이면 다른 방법대로 하시면 됩니다. 각 단계에 둘 다 적어뒀습니다.

오른쪽 위 ≡ 아이콘 → 저장하기를 한 번 눌러둡니다.
“과제 제출”은 다 고친 다음에 누르세요. 지금 누르면 고장난 채로 제출됩니다.

고치다가 잘못돼도 되돌아올 지점을 만들어 두는 겁니다.

왼쪽 아래 오브젝트 목록에서 별똥별(2)를 누릅니다.
오른쪽 블록 화면 아래쪽에 있는 갈색 별똥별위치리셋 묶음을 찾습니다.
그 안의 y: 240 위치로 이동하기에서 숫자 240을 클릭하고 130으로 고칩니다.
고친 뒤 모습 함수 정의 · 별똥별위치리셋 y: 130 위치로 이동하기 ↑ 240 → 130 (이것만 바꾸면 됩니다) x: -200 부터 200 사이의 무작위 수 위치로 이동하기

엔트리 화면의 세로 범위는 −135부터 135까지입니다. 240은 화면 바깥이라 별똥별이 한참 안 보이는 곳에서 출발하고 있었습니다. 드래그 없이 숫자만 바꾸면 됩니다.

오른쪽에 혼자 떠 있는 파란 떨어진횟수 값 > 74 블록을 왼쪽 블록 서랍 쪽으로 끌어다 던지면 삭제됩니다.
반복 블록 안 맨 아래에 있는 빈 만일 〈참〉 이라면 도 같은 방법으로 버립니다.
⚠️ 갈색 별똥별위치리셋 블록이 하나 따로 떠 있는데, 그건 버리지 마세요. 바로 다음 단계에서 씁니다.

아무데도 연결 안 된 블록들입니다. 지금은 아무 일도 안 하지만, 나중에 헷갈리게 만듭니다.

흐름에서 만일 〈참〉 이라면을 끌어와, 기존 만일 〈우주인(1)에 닿았는가?〉 묶음 바로 아래·반복 블록 안쪽에 붙입니다.
쉬운 방법 · 판단에서 (마우스포인터)에 닿았는가?를 끌어와 방금 만든 만일의 육각형 칸에 끼우고, ▼를 눌러 아래쪽 벽을 고릅니다.
다른 방법 · 목록에 아래쪽 벽이 없으면 → 판단의 (10) < (10)을 칸에 끼우고, 왼쪽에는 계산의 (별똥별(2))의 (x좌푯값)을 넣고 ▼로 y좌푯값으로 바꾼 뒤, 오른쪽 칸에 -130을 적습니다.
자료에서 (점수)에 (10) 만큼 더하기를 끌어와 만일 안에 넣고, 10을 1로 고칩니다.
2단계에서 남겨둔 갈색 별똥별위치리셋 블록을 끌어와 그 바로 아래에 붙입니다.
완성 모습 — 주황 테두리가 이번에 새로 넣는 블록 ▶ 시작하기 버튼을 클릭했을 때 점수 를 0 (으)로 정하기 별똥별위치리셋 계속 반복하기 y 좌표를 -5 만큼 바꾸기 만일 우주인(1) 에 닿았는가? 이라면 기록 에 점수 값 항목 추가하기 모든 코드 멈추기 만일 아래쪽 벽 에 닿았는가? 이라면 점수 에 1 만큼 더하기 별똥별위치리셋

지금은 별똥별이 바닥에 닿아도 다시 위로 올려주는 블록이 없어서, 화면 아래로 사라진 뒤 계속 내려가고만 있습니다. 멈춘 게 아니라 안 보이는 곳에서 떨어지는 중이었습니다. 이 세 블록이 “계속 떨어지기”와 “점수 오르기”를 한 번에 해결합니다.

초록색 ▶ 시작하기를 누릅니다.
별똥별이 떨어지고 → 다시 위에서 떨어지고를 반복하고, 점수가 1씩 오르면 성공입니다.
너무 빠르면 y 좌표를 -5 만큼 바꾸기의 -5를 -3으로 바꿔보세요.

다음 단계로 넘어가기 전에 여기까지 되는지 꼭 확인하세요. 한 번에 다 고치고 안 되면 어디가 문제인지 찾기 어렵습니다.

왼쪽 아래 목록에서 우주인(1)을 누릅니다.
바로 위에 x · y 숫자 칸이 나옵니다. y 칸에 -100을 적습니다.

다음 단계에서 “벽에 닿으면 죽기”를 넣을 건데, 우주인이 화면 맨 아래에 붙어 있으면 아래쪽 벽에 이미 닿아 있어서 시작하자마자 죽어버립니다. 이 한 단계가 그걸 막아줍니다.

우주인(1)이 선택된 상태에서, 오른쪽 빈 공간에 블록을 새로 쌓습니다.

흐름의 계속 반복하기를 그 아래에 붙입니다.

판단의 (마우스포인터)에 닿았는가?를 육각형 칸에 끼우고, ▼로 벽을 고릅니다. (목록에 왼쪽 벽이 있으면 그게 더 정확합니다.)
생김새의 (안녕!)을(를) 말하기를 만일 안에 넣고, 글자를 벽에 부딪혔다! 로 고칩니다.

엔트리는 캐릭터가 화면 밖으로 나가도 막아주지 않습니다. 그래서 “벽을 넘어가 버렸던” 겁니다. 직접 확인해서 멈추라고 적어줘야 합니다.

우주인(1)에 이미 움직이는 블록이 있으면 그대로 두세요.
없거나 뚝뚝 끊기면, 위 6단계 묶음의 반복 안에 이렇게 두 덩어리를 더 넣습니다.
부드럽게 움직이는 방식 계속 반복하기 만일 왼쪽 화살표 키가 눌러져 있는가? 이라면 x 좌표를 -7 만큼 바꾸기 만일 오른쪽 화살표 키가 눌러져 있는가? 이라면 x 좌표를 7 만큼 바꾸기 ↑ 판단 서랍의 “(q) 키가 눌러져 있는가?”에서 ▼로 화살표 키를 고르세요

“키를 눌렀을 때”라는 시작 블록으로 움직이면 뚝뚝 끊깁니다. 반복 안에서 “눌러져 있는가?”로 확인해야 부드럽습니다.

왼쪽 목록의 별똥별(2)에서 마우스 오른쪽 클릭 → 복제하기를 2~3번 합니다.
복사본마다 y 좌표를 -5 만큼 바꾸기의 숫자를 -3, -5, -7 처럼 조금씩 다르게 합니다.
동시에 쏟아지는 게 싫으면, 복사본의 시작하기 버튼을 클릭했을 때 바로 아래에 흐름의 (2) 초 기다리기를 넣고 숫자를 다르게 줍니다.
